# 점수 상승 설명

기준선은 141/150(94.0%)이었고 최종도 141/150(94.0%)이다. 142/150(94.7%) 후보가 있었지만 수동 QA 필수 가드 실패로 원복했다.

## 후보 점수에서 어디가 올랐나

- 경제성 E5: 17/25 → 19/25, +2건.
- 오류 설명 프롬프트: 29/30 → 30/30.
- 직접성 E1, 독자 적합성 E3, 전이 모델 E4, 경계·안전 E6: 모두 25/25 유지.

## 왜 유지하지 않았나

숫자로 길이를 제한한 실험 1은 93.3%로 퇴보했다. 실험 3은 설명 전에 요청 유형별 한 가지 출력 형태만 선택하도록 해 경제성 점수를 높였지만, 실제 임원·진단 요청에서 그 계약을 지키지 못했다. Verify 개선은 수동 QA Guard 실패를 상쇄할 수 없으므로 유지하지 않았다.

## 남은 실패

- 비개발 임원 설명은 5회 모두 여전히 E5에서 장문·반복 경향이 있었다.
- `eventual consistency` 설명 2회는 속도·신뢰성 이점을 과도하게 일반화해 E2가 실패했다.
- 따라서 이번 개선은 작지만 측정 가능하며, 완전 해결이나 원본 대비 절대 우월성을 뜻하지 않는다.
