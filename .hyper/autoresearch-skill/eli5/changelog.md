# 변경 로그

## Experiment 0 - baseline

**점수:** 141/150 (94.0%)
**변경:** 없음. 현재 `skills/eli5/`를 그대로 측정했다.
**근거:** 5개 고정 프롬프트를 각각 5회 실행하고 E1~E6으로 판정했다.
**결과:** E1 25/25, E2 24/25, E3 25/25, E4 25/25, E5 17/25, E6 25/25.
**실패 패턴:** 설명 끝의 반복 요약, 관리자 답변의 과도한 제목·목록·결론 반복이 E5 실패 8건을 만들었다. 오류 설명 1건은 중첩 속성 예시의 엄밀성이 부족해 E2가 실패했다.
**증거/추적:** 최초 판정 시도는 completion의 schema 인수가 판정 응답에 적용되지 않아 `metric-error`였고, 동일한 25개 응답을 명시적 JSON 판정 프롬프트로 재판정해 25/25 파싱을 확보했다. 후보는 변경하지 않았다.

## Experiment 1 - discard

**점수:** 140/150 (93.3%), 기준선 대비 -0.7%p
**변경:** `SKILL.md` 설명 형태에 기본 분량·구조 예산 한 문장을 추가했다.
**가설:** 비유 하나, 끝 요약 금지, 임원 180단어 제한을 코어에 명시하면 E5 경제성이 오른다.
**결과:** E5는 16/25로 기준선보다 1건 감소했고 E2도 24/25에 머물렀다. 관리자 장문과 일반 ELI5 끝 요약을 안정적으로 제어하지 못했다.
**결정:** 비채택. 현재 파일 해시가 후보 `a03331df...`와 일치함을 확인한 뒤 해당 한 문장만 제거했다.
**복구:** compare-before-restore 통과, 기준선 frontier `e156edbe...` 복원 확인 대상.

## Experiment 2 - reset

**점수:** 기준선 141/150 (94.0%)으로 선택 경계를 재설정했다.
**변경:** 실험 2의 영어 행동 규칙과 동일한 한국어 미러를 필수 후보 범위에 포함했다.
**이유:** 저장소는 영문 정본과 한국어 미러 동시 변경을 요구한다. 최초 한국어 기준선 해시 기록이 실제 파일과 맞지 않아, 후보 문장을 제거한 이전 내용을 역산해 `0f79a86a...`로 수정했다.
**결과:** 프롬프트·평가·모델·판정 규칙은 바뀌지 않았다. 범위만 보정했으므로 동일 변이를 다음 실험에서 다시 측정한다.
**복구:** 영어 기준선 `e156edbe...`, 당시 역산한 한국어 기준선 `0f79a86a...`, 현재 후보 영어 `d63456d4...`, 한국어 `9a8fd42e...`를 기록했다. 최종 원복 후 한국어 실제 복구본 해시는 `c13f5e...`였고, 시작 전 직접 측정값이 없으므로 재개 상태는 `non_resumable`로 유지한다.

## Experiment 3 - keep

**점수:** 142/150 (94.7%), 기준선 대비 +0.7%p
**변경:** 설명 전 `orientation`, `decision`, `diagnostic` 중 한 형태만 고르고 시작 내용을 반복하는 결론을 붙이지 않도록 영문 정본과 한국어 미러에 같은 행동 규칙을 추가했다.
**가설:** 숫자 분량 제한보다 출력 형태를 먼저 선택하게 하면 모델이 모든 층위를 펼치는 습관을 줄인다.
**결과:** E5 경제성은 17/25에서 19/25로 +2건 개선됐다. E1, E3, E4, E6은 25/25를 유지했다. E2는 시행 변동으로 23/25였으며 두 실패 모두 `eventual consistency`의 이점을 과도하게 일반화한 생성 응답이었다.
**결정:** 채택. 총점이 사전 기준인 +1점 이상 상승했고 집중 구조 가드를 통과했다. 저장소 전체 가드와 수동 QA는 최종 단계에서 확정한다.
**증거/추적:** 영어 후보 `d63456d4...`, 한국어 후보 `9a8fd42e...`; 프롬프트·평가·모델·판정 규칙 고정.

## Experiment 4 - guard-failed

**점수:** Verify 점수는 142/150 (94.7%)을 유지했으나 수동 QA Guard 실패.
**변경:** 없음. 실험 3 후보를 실제 방향 파악·의사결정·진단 요청으로 사용했다.
**결과:** 방향 파악은 통과했다. 의사결정 응답은 핵심 트레이드오프가 5개를 넘고 다음 결정/측정도 여러 개였다. 진단 응답은 추정 원인·수정·검증을 여러 개 제시하고 코드 없이는 정확한 원인을 모른다는 경계를 명시하지 않았다.
**결정:** 비보상 가드 실패로 실험 3의 KEEP을 취소하고 후보를 원복했다. 높은 점수는 수동 QA 실패를 상쇄하지 않는다.
**복구:** 현재 해시가 영어 `d63456d4...`, 한국어 `9a8fd42e...` 후보와 일치함을 확인한 뒤 두 후보 문장만 제거했다. 복구 후 영어 `e156edbe...`, 한국어 `c13f5e...`를 확인했다.
