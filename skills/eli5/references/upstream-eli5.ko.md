## 원본이 잘 확립한 점

- ELI5와 특정 대상 설명을 위한 명시적 활성화 문구.
- 연령, 교육, 직무, 관계 대상의 유용한 구분.
- 대상이 무엇인지, 비유, 세부사항, 중요한 이유로 이어지는 명확한 기본 구조.
- 기술 독자와 비즈니스 독자의 서로 다른 우선순위.
- 세 가지 사례에 대한 스킬 적용/미적용 쌍 평가.
- 보고된 설정에서 주장한 91.7% 대 33.3%의 검사항목 통과율.

이 비율은 원본의 보고이며 이 패키지에서 재현한 근거가 아니다. 사례 수, 모델/스캐폴드 세부사항, 판정기 동작, 공개 테스트 오염 위험 때문에 직접 비교에는 한계가 있다.

## 복사하지 않은 내용

- 5세에게 장난감, 청소년에게 소셜 미디어, 성인에게 주택 소유, 배우자에게 가사 역할을 지정하는 인구통계 기반 비유 처방.
- 비기술 독자에게 80% 정확도가 더 낫다는 지시.
- 관리자에게 모든 서식을 금지하는 규칙. 대신 결정에 도움이 되는지로 판단한다.
- 이 저장소는 스킬 스크립트 목록을 통제하고 Markdown 전용 설명 스킬에 런타임 헬퍼가 필요하지 않으므로 Python 평가 실행기.
- 원본 산문 예시. 로컬 평가 세트에는 독립적으로 작성한 사례를 사용한다.
