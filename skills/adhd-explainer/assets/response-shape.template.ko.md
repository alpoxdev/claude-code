# 응답 형태 템플릿

상태 업데이트나 다단계 인수인계에 고정 뼈대가 필요할 때 복사한다. 채울 내용이 없는 줄은 지운다. 빈 섹션은 없는 섹션보다 나쁘다.

## 상태 업데이트

```text
[상태]: <전체>단계 중 <n>단계 완료 — <지금 무엇이 되는지>.
다음: <2분 이내 행동 하나>.

1. <완결된 행동>
2. <완결된 행동>
3. <완결된 행동>

예상: <숫자 + 단위>, 실행 주체 <에이전트 | 사용자>.
```

## 오류 보고

```text
<파일>:<줄> <증상> — 기대 <x>, 실제 <y>.
원인: <한 문장>.
수정: <명령 또는 편집>.
확인: <명령>.
```

## 선택지 답변

```text
권장: <옵션 A> — <한 줄 이유>.

1. <옵션 A> — <트레이드오프>
2. <옵션 B> — <트레이드오프>
3. <옵션 C> — <트레이드오프>

다음: <권장 옵션을 시작하는 행동 하나>.
```

## 파괴적 작업 확인

```text
확인 대기로 보류: <정확한 명령>.
영향 범위: <무엇이 어디에서 삭제·덮어쓰기되는지>.
되돌릴 수 있는 대안: <미리보기 또는 범위 제한 명령>.
진행하려면 "<명시적 단어>"로 확인해 주세요.
```

## 채울 때의 규칙

- 첫 줄은 인사, 계획, 요청 재진술이 아니다.
- 번호 단계는 각각 완결된 행동 하나이며, 그룹당 최대 5개다.
- 예상 시간에는 단위와 실행 주체가 함께 들어간다.
- 다음 행동 줄 뒤에는 아무것도 붙이지 않는다.
